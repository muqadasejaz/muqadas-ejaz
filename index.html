01How I work

Hi, I'm Muqadas. I turn AI ideas into working systems.

Every project starts with the problem, not the model. I look at the data first, pick the simplest approach that could work, and only add complexity when the results ask for it.

From there I handle the full path: preparing data, training and fine-tuning, and testing on data the model hasn't seen. Then I wrap it in an API or a simple app, so people can try it instead of just reading about it.

Benchmarks are where I start, not where I stop. The real test is how a system holds up on messy, real-world inputs, and that's where I spend most of my time.
